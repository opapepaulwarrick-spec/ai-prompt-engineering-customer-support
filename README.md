AI Prompt Engineering – Customer Support

Objective

Test three AI tools for customer-support message classification and compare their results with a manual classification.

AI tools

ChatGPT / OpenAI

Claude / Anthropic

Gemini / Google

Workflow

Classify the 12 customer messages manually.

Record the manual categories before using AI.

Test the same messages with the three AI tools.

Compare AI classifications with the manual classification.

Identify correct classifications, errors, and differences.

Improve the prompts and retest.

Repository structure

notes.md – five prompt-engineering techniques and sources

manual-classification.md – the 12 messages classified manually

prompts/ – prompts tested with each AI tool

results/ – AI classification results and comparison

README.md – project overview
